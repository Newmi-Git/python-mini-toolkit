# python-mini-toolkit
#DESCRIPTION
This is a short python project that consists of 5 tools the user is able to access. These tools can be used for every day life or just for a fun activity#

#Features
-Grade Calculator
-To-Do List
-Even or Odd Checker
-Number Guessing Game
-Simple Quiz Game

#Python Concepts Used:
Variables, data types, user input, output, and type casting
Arithmetic, assignment, comparison, and logical operators
if, elif, else statements, nested conditions, and boolean expressions
for loops, range, while loops, and loop control
Functions, parameters, arguments, return values, and passing functions as arguments
Lists- Built-in modules and custom module

#How to run the project
Open Project using an IDE that can run Python Files, preferably VS Code, and install a code runner or use a built-in coderunner(if your IDE provides it) to run the project within the Terminal
